# MonkeyHub documentation

Every document sits in one category below; this index is the only file at the docs root. The
repository's [README](../README.md) introduces the project, [AGENTS.md](../AGENTS.md) holds the durable
rules and [CONTRIBUTING.md](../CONTRIBUTING.md) the working process. Current work and its acceptance
are [GitHub Issues](https://github.com/cogco1/MonkeyHub/issues); who owns which code is the
[module registry](../governance/module_registry.json), rendered as the [system map](architecture/system-map.md).

## Naming

File and directory names are lowercase kebab-case; a decision is `decisions/NNN-short-name.md`; a date
belongs in the document's front matter (`created: YYYY-MM-DD`), not in its name; only `prototypes/`
keeps files that are not Markdown. The rules are in
[repository layout §6.1](architecture/repository-layout.md#61-命名规则), and `python tools/governance/archcheck.py`
checks the files Git tracks.

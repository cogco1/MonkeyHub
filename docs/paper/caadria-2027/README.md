# CAADRIA 2027 paper workspace

This directory is a human-facing, non-canonical paper workspace for the
ArchFlow CAADRIA 2027 submission.

It does not own project state, experiment state, provider authority, validation
authority, or empirical results. Runtime and experiment truth remain in the
P036 project records and promoted probe evidence. Paper files may cite and
summarise those records, but must not repair, infer, normalise, or silently omit
their outcomes.

## Authority rules

1. A contract test is mechanism evidence, not a model outcome.
2. A diagnostic or recovery study is failure-analysis evidence, not a P062
   assignment result.
3. Only exact completed experiment outcomes may enter an empirical table.
4. Failed, timed-out, rejected, unknown, planned, and interrupted cells remain
   visible.
5. Every empirical claim and figure must retain source record references and
   content digests.
6. The manuscript must distinguish implemented mechanism, measured result,
   inference, proposal, and limitation.

The current source boundaries are defined by
[EXPERIMENT_PROTOCOL.md](../../EXPERIMENT_PROTOCOL.md),
[P062](../../mapping/planning/P062-multi-building-experiments-and-ablations.md),
and [ARCHITECTURE.md](../../ARCHITECTURE.md).

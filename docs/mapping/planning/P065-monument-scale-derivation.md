# P065 — Monument-scale staged derivation

- Origin: Planning
- Status: Ready
- Depends on: P058, P062, P064, M065

## Goal

Prove that staged derivation plus typed repetition reaches golden-sample
complexity: a scripted P053 provider derives a monument-class
drum-and-dome building through the formal runtime in bounded stages on
stable component identities, realizing hundreds of typed instances through
arrays.

## Design

- Root step through `run_or_resume_production_step` with a scripted
  provider (P058 precedent): coarse portico/rotunda/dome massing.
- At least three P055 exact-predecessor deepening stages on the same
  component identities: openings and colonnade; drum ring articulation;
  radial coffer field.
- Typed arrays (linear and M065 radial) expand order-tens of authored
  operations into hundreds of realized instances.
- A derived voxel view retains solid-cell scale evidence in the probe;
  a separate machine-local fidelity tool measures the coarse envelope
  against the frozen golden and promotes the receipt with its source
  manifest.

## Claim boundary

Scripted-provider protocol proof only; a live-model monument run is a
separately evidenced future card. No engineering, fabrication, or
full-fidelity claim. The golden sample is an external yardstick, not a
reloaded answer.

## Stop conditions

- Stop if any stage would load golden geometry as a generated output.
- Stop if component identities fail exact-predecessor checks.
- Stop before claiming live-model capability from scripted evidence.

## Tests

- Staged-derivation integration test: identity stability, array instance
  counts, voxel scale, reload provenance.
- Architecture V3 scope diff, compileall, full discovery.

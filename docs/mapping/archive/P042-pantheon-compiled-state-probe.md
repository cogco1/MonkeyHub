# P042 — Agent-compiled Pantheon operational-state probe

- Origin: Planning
- Status: Done
- Depends on: P037, P041

## Goal

Use one research-capable Agent as the project-scoped design author for a
Pantheon probe and test how far the P041 compilation state can organize a real
architectural derivation before geometry generation exists.

The Agent may retrieve evidence and author case-specific typed design moves.
All Pantheon facts, hypotheses, parameters, commitments, obligations,
dependencies, and state traces remain inside `probes/test_pantheon/`. V3 may
contribute output-package and provenance protocol, but no V2/Pack generation
authority or building answer may enter V4 framework code.

This is an intermediate compiled-design dossier, not P038 full-flow acceptance:
it cannot claim a generated candidate, architectural usability, or Minecraft
success.

## Acceptance

- The existing raw request remains the only authored project input.
- Retrieved sources are retained as project-scoped evidence with URL,
  publisher, access date, claim, certainty, and unresolved-status fields.
- A named Agent authors exact-base `DecisionOperator@1` records rather than a
  hand-coded framework branch.
- The run retains initial and successive `OperationalMarkovState@2`,
  `StateDelta@1`, closure receipts, Agent rationale, evidence references, and
  unresolved questions through `FilesystemProjectRepository`.
- At least one upstream revision follows explicit dependencies, invalidates
  only affected downstream outputs, and creates revalidation obligations.
- V3 protocol references are mapped into logical project records; unverified
  V3 Gold, V2 composer, Pack defaults, coordinates, and whole-building
  generation code have no authority.
- Reload after restart verifies every retained record digest and exact state
  chain.
- The probe reports the deepest supported design maturity honestly and keeps
  `generation_authority=false` and `architectural_usability_proven=false`.
- Framework files receive no Pantheon, rotunda, dimension, column-count,
  material, topology, or named-expert default.

## Tests

- Raw-input-only preservation.
- Evidence provenance and uncertainty fields.
- Exact-base operator/state/closure chain.
- Local transitive invalidation and generated obligation.
- Repository close/reopen and digest verification.
- V3 protocol/legacy authority separation.
- No framework instance-answer scan.
- No candidate, canonical promotion, geometry, or usability overclaim.

## Stop conditions

- Stop if the Agent must invent a source, historical fact, user preference, or
  missing design authority.
- Stop before placing project facts or design answers in `archflow/`.
- Stop before treating V3/V2 output as current generation authority.
- Stop if a retained record bypasses the project repository.
- Stop before calling the dossier a generated or usable building.

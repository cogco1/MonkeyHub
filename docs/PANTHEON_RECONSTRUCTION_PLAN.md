# Pantheon reconstruction plan — stage decision registry

**Status:** planning document for the reconstruction-grade derivation.
Every numeric value below is a *candidate* until a P067 adoption record
binds it to a retained source (the Wikipedia snapshot already retained in
`p066-live-monument`, the golden manifest, and scholarly sources to be
snapshotted — Mark & Hutchinson 1986, Lancaster 2005, Wilson Jones 2000).
Values marked ✓ are already quoted in retained evidence; values marked ◌
must be adopted before use. The framework never owns any of them.

Scale: full scale in metres. Footprint grid 4 m² per cell (2 m cells)
keeps the full plan inside the 4096-cell bound.

## Stage 0 — 场地与体量 (scheme gate / white model)

RIBA 2 sign-off · 方案设计深度 · AIA schematic. Passing this gate
compiles the site and massing-and-grid quadrants into HARD COMMITMENTS.

**尺寸 (declarations, geometry-cross-checked):**
- 主轴朝向:正北入口,南北主轴 ◌(实体朝北)
- 圆厅内径 = 至顶眼内高 = 43.3 m ✓(快照原句;球体内切规则)
- 鼓座外径 ≈ 56.2 m(43.3 + 2 × 6.4 壁厚)◌
- 门廊平面 ≈ 33.1 × 15.6 m ◌;过渡块进深 ≈ 4–5 m ◌
- 总长(门廊+过渡块+鼓座)≈ 76–78 m;总高 43.3 m + 顶眼环构造
- footprint 填充率下限与场地定位(前院台阶 5 步 ◌)

**结构 (system choice = irreversible):**
- 体系选型:罗马混凝土鼓座承半球穹;鼓座为 8 墩 + 8 龛的掏空环,
  非均匀实心环 ◌
- 主跨 43.3 m ✓;起拱高 21.65 m(= 半径,半球从中高起拱)几何推论
- 基础:混凝土环基 ≈ 7.3 m 宽 × 4.5 m 深 ◌

**空间关系 (committed axioms):**
- 三段串联:门廊 → 过渡块/门厅 → 圆厅,单一贯通主轴
- 入口龛与正对主龛(apse)占轴线两端;球体内切为强制标准
- 门廊为半室外(有顶无侧墙),圆厅全围合顶部唯一采光(oculus)

**材质 (system-level only):**
- 结构材料制式:opus caementicium(罗马混凝土)+ 砖砌面层 ✓
- 骨料分级原则声明(重→轻随高度)◌;面层材料留待后续门

**本门必填声明字段(P068 契约):** orientation_axis, interior_span_m,
interior_height_m, drum_outer_diameter_m, wall_thickness_m,
portico_width_m, portico_depth_m, total_length_m, springing_height_m,
structural_system, primary_grid, footprint_fill_ratio, foundation_ring.

## Stage 1 — 结构与外皮 (spatial-coordination gate)

RIBA 3 · 初步设计深度(高度层数面积+结构选型必须闭合)。通过后
skin-and-openings 象限编译为承诺。

**尺寸:**
- 鼓壁厚 6.4 m ◌;鼓座外部三层带檐口划分 ◌
- 顶眼开口 Ø ≈ 8.8 m(结构承压环 Ø 9.1 m ✓ 快照)
- 大门洞 4.45 × 7.53 m ◌;台阶五步升高 ◌
- 柱:16 根整料柱,柱身 11.9 m ✓ × 底径 ≈ 1.48 m ◌,柱头 2.4 m ✓
- 檐部与山花:entablature/柱高比 canon [0.2, 0.25](金样 trace ✓);
  山花坡顶,门廊屋脊高 ≈ 25 m ◌

**结构:**
- 鼓座掏空体系成形:8 墩 + 8 龛(半圆/矩形交替)✓(快照:niches)
- 穹壳厚度渐变 6.4 m(基)→ 1.2 m(顶眼环)◌
- 穹顶外部 7 道阶环(压重减推力)◌
- 减重拱制式声明(体素级以龛与空腔表达,拱本体为记录级声明)◌
- 门廊结构:八柱式 + 后两组四柱 ✓,楣梁-桁架顶

**外皮/开口:**
- 八柱式正立面、三角山花(原鹰雕饰面记录为佚失)✓
- 过渡块上第二山花痕迹(可选,考据记录 ✓ 快照)
- 外墙砖面层 + 原大理石贴面痕迹声明 ◌

**空间关系:**
- 龛环八向方位角确定;入口与 apse 锁定主轴两端
- 门廊柱距(中央跨放宽以对位大门)◌

**材质:**
- 柱身:灰/玫瑰花岗岩(埃及整料)◌;柱头柱础:白大理石 ◌
- 穹顶骨料分级落数:玄武岩/石灰华(基)→ 凝灰岩 → 浮石(顶)◌
- 门:青铜 ✓(古门尚存)

**本门必填:** wall_thickness_m, oculus_diameter_m, door_w_m, door_h_m,

## 执行路线(下一步顺序)

1. **P068 收尾**:场地象限字段、声明→承诺过门编译、按本文档生成
   Stage 0 契约(值域来自采纳记录)。
2. **补采纳证据(P067 通道)**:对上表全部 ◌ 值逐条检索-引用-采纳
   (Wikipedia 快照已含大量 ✓;补 Mark & Hutchinson / Lancaster /
   Wilson Jones 快照)。凡采纳不到可靠出处的值,声明区间放宽并记录
   不确定性,不得编造。
3. **M069 材质通道**:组件级材料意图记录 → 场景对象材料标签 →
   标准出图按材料着色;材质"正确"= 材料指派与来源可审计,
   非体素质感拟真。
4. **P069 脚本参照推导**:按本表四阶段走完全尺寸(2 m 格)复原,
   每阶段过声明门 + 阶段 P060 标准;终局对金样与对采纳尺寸双重
   保真度测量。脚本参照即阶段契约的验收测试。
5. **P066 实机接管**:同一契约换实机 provider,逐阶段配对记录;
   声明门保证实机不能再交细塔或平顶。
